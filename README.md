# off-duty-report

This tool streamlines data entry, review, and export of off-duty work reports.

* Data Entry & Management: 
Each page holds 20 rows for logging date, employer, work type, and time worked. Hours are calculated automatically from start/end times. The "Running Total" sums hours across all pages, and you can add or remove pages as needed.

* Signature Capture: 
Two signature pads (Officer and Commander) are included per page. Sign with mouse or touch, and clear with a single click.

* Save & Load Progress: 
Use the "Save Progress" button to download a .json backup file, and "Load Progress" to restore a previous session. Data also auto-saves in your browser's local storage.

* Print & PDF Export: 
Both "Print" and "Export as PDF" produce a clean, single-page layout with appropriate margins. The column widths (especially "Type of Work") have been reduced to save space, and the header logos now have balanced spacing from the title text.
