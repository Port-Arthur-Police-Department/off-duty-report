To get the pwa icon to work, I used favicon.io to download the images and the site.manifest, after this I had to update the html tags in the index.html file.  This was my instructions from deepseek:

I recommend replacing your current icon setup with the new one from favicon.io. The generated icons are properly sized for all devices, and the manifest is correctly formatted. This should resolve the download error you're seeing.

Here’s how to implement it:

1. Replace your HTML <head> tags
Replace your current icon-related tags with these:

html
<link rel="apple-touch-icon" sizes="180x180" href="/off-duty-report/apple-touch-icon.png">
<link rel="icon" type="image/png" sizes="32x32" href="/off-duty-report/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="16x16" href="/off-duty-report/favicon-16x16.png">
<link rel="manifest" href="/off-duty-report/site.webmanifest">
Note: I've added /off-duty-report/ to the paths because your site is hosted at https://port-arthur-police-department.github.io/off-duty-report/. If you place the icons in the root of your repository, they'll be served from that subfolder. Adjust the paths if your icons are in a different location.

2. Update your manifest file
Rename your current manifest.webmanifest to site.webmanifest (or just use the one generated by favicon.io). If you want to keep your current manifest content (with your app name and theme color), merge it with the generated one. Here’s a combined version:

site.webmanifest

json
{
  "name": "Secondary Employment Report",
  "short_name": "Sec. Employment",
  "start_url": "/off-duty-report/index.html",
  "display": "standalone",
  "background_color": "#f4f5f7",
  "theme_color": "#1e3a5f",
  "icons": [
    {
      "src": "/off-duty-report/android-chrome-192x192.png",
      "sizes": "192x192",
      "type": "image/png",
      "purpose": "any maskable"
    },
    {
      "src": "/off-duty-report/android-chrome-512x512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "any maskable"
    }
  ]
}
3. File structure
Make sure these files are in your repository's root (the same folder as index.html):

text
/off-duty-report/
├── index.html
├── site.webmanifest
├── apple-touch-icon.png
├── favicon-32x32.png
├── favicon-16x16.png
├── android-chrome-192x192.png
└── android-chrome-512x512.png
4. Why this is better
Proper sizing – each icon is correctly sized for its purpose (desktop, mobile, tablet).

No download errors – the icons are valid PNG files that the browser can read.

Better browser support – includes all the necessary sizes for different platforms.

Maskable support – the icons will adapt properly on Android devices.

5. What to do with your old files
You can keep or delete:

icon.png – you can remove it since the new icons replace it.

manifest.webmanifest – rename or delete it; site.webmanifest will be used instead.

badge.png and patch.png – these are separate logos for the report itself and should stay.

6. Test it
After deploying the changes:

Clear your browser cache (Ctrl+Shift+Delete).

Open your site.

Open DevTools → Application → Manifest – you should see the icons loaded without errors.

Install the app – the desktop shortcut should now use the correct icon.
